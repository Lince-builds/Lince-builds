[查看能力与制作流程](https://github.com/Lince-builds/anime-editing-skill#制作流程一览) · [安装与开始](https://github.com/Lince-builds/anime-editing-skill#安装与开始) · [反馈问题](https://github.com/Lince-builds/anime-editing-skill/issues)

## 从一个具体创意开始

在 Codex 中安装这个 Skill：

```text
请帮我安装这个 Skill：https://github.com/Lince-builds/anime-editing-skill
```

安装后，可以这样提需求：

```text
使用 $anime-editing，把我的动漫二创想法整理成镜头方案。
素材由我提供，先核对原作和可用镜头，验证最难的动作。
本轮先交分镜与关键短样，再决定后续剪辑。
```

这是面向 Codex 的制作方法和配套工具。实际动画、语音与剪辑需要另行准备工具和素材；完整跨机器复现仍待验证。具体能力与已验证范围见仓库说明。

欢迎带着一个创意来试，也欢迎在 [Issues](https://github.com/Lince-builds/anime-editing-skill/issues) 里留下使用的工具、卡住的步骤和实际结果。
